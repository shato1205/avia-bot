# Бот дешёвых авиабилетов и билетов на поезда

Каждые 30 минут проверяет цены через Travelpayouts (данные Aviasales) и присылает
в Telegram сообщение вида «🔥 ГОША СРОЧНО ТАИЛАНД (Пхукет) 18 500 ₽», если билет
дешевле порога из `config.json` или на 30% дешевле медианы за последние 30 дней.

## Настройка (один раз)

1. **Токен Travelpayouts.** Зарегистрируйся на travelpayouts.com, открой
   «Профиль → API токен» и скопируй его.
2. **Telegram-бот.** Напиши @BotFather команду `/newbot`, получи токен бота.
   Затем напиши своему боту любое сообщение и открой
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`: число `chat.id` это твой chat id.
3. **Секреты в GitHub.** В репозитории: Settings → Secrets and variables → Actions →
   New repository secret. Добавь `TRAVELPAYOUTS_TOKEN`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.
4. **Первый запуск.** Вкладка Actions → «Проверка цен» → Run workflow.

## Меню в Telegram

Внизу две кнопки: «🏠 Меню» и «💰 Цены сейчас». Всё остальное делается кнопками под сообщениями.

- **Главное меню**: города вылета и кнопка «➕ Город вылета» (популярные города или свой).
- **Экран города**: каждое направление отдельной кнопкой с порогом и последней ценой,
  кнопки «➕ Направление», «🎯 Подбор по датам», «💰 Цены сейчас», «🗑 Удалить город».
- **Добавление по шагам**: город (кнопкой или текстом) → для подбора месяц или даты и
  туда-обратно/в одну сторону → порог цены (бот сразу показывает текущую цену).
- **Карточка направления** (нажать на направление): порог ±1к/±5к или своя цена,
  даты, туда-обратно, только прямые, время в пути, пауза, цена сейчас, удаление.
- **Пересадки и багаж.** В каждом билете видно авиакомпанию, прямой рейс или пересадки
  (с городами и пометкой «⚠️ смена аэропорта»), время в пути и багаж по тарифу из ссылки
  Aviasales («🧳 Багаж включён: 23 кг» или «🧳 Без багажа»); если тарифа нет, у лоукостеров
  пометка «багаж, скорее всего, за доплату».
  Билеты с долгими пересадками бот отсеивает: кнопка «⏱ В пути» в карточке переключает
  «авто» (не дольше самого быстрого варианта + 10 часов и не больше 30 часов на сторону),
  «до 12/16/20/24/30 ч» и «любое».
  «Цена сейчас» показывает ещё самый быстрый вариант и самый дешёвый из отсеянных.
- **Обратный билет.** Под каждым билетом «туда» бот пишет, сколько стоит туда-обратно одним
  билетом с тем же вылетом и сколько стоит обратный билет отдельно (и сумму). Когда лететь
  обратно, выбирается кнопкой «↩️ Когда обратно» в карточке: неделя, 10 дней, 2 недели,
  3 недели, месяц, любой срок (5–30 дней) или кнопка «✏️ Вписать свою дату», после которой
  можно написать «25.12», «20.12-28.12», «12» (дней) или «10-14» (дней).
- Под каждым уведомлением кнопки «🎫 Купить билет», «⚙️ Настроить» и «⏸ Пауза».

- **🚆 Поезда** (кнопка в главном меню): откуда → куда (популярные города кнопками
  или любая станция текстом) → тип вагона → даты → порог цены. Даты выбираются в календаре
  кнопками (на 4 месяца вперёд) или ближайшими выходными; кнопкой «✏️ Вписать свою дату»
  можно написать один день или до 7 дней подряд («15.12-20.12»); есть и «Любая дата».
  - **Туда-обратно**: после даты «туда» бот спрашивает «когда обратно?» (календарь, своя дата
    или «➡️ Только туда»). Тогда он ищет самый дешёвый билет туда и самый дешёвый обратно
    (обратный поезд позже прибытия туда), порог и уведомления — по общей цене, у каждого билета
    своя кнопка «🎫 Купить». В карточке поезда дату обратно меняет кнопка «🔁 Обратно».
  - С датами бот спрашивает Туту.ру так же, как сайт (`offers-api.tutu.ru`): точные цены
    и свободные места на эти дни. Берётся обычная цена, без скидки по карте Альфа-банка.
  - Без дат — расписание Туту.ру через Travelpayouts: цены «от» без конкретной даты.
  - Сайты РЖД с зарубежных серверов не открываются, поэтому РЖД напрямую не используется.
  - Карточка поезда: порог ±500/±1к, даты, тип вагона, пауза, цена сейчас (три самых
    дешёвых поезда). Поезда с прошедшими датами удаляются сами.
  - Один и тот же поезд по той же цене повторно не присылается неделю.
    Справочник станций лежит в `stations.json`.
- Под уведомлениями и ценами есть кнопка «🎫 Купить билет» (Aviasales или Туту.ру на нужную дату).

Текстом тоже можно: «откуда Казань», «добавить Бали 35к», «подбор Пхукет 15.12-25.12 до 60000».
Настройки лежат в `data/settings.json`, начальные берутся из `config.json`.

## Друзья (по приглашению)

- Владелец (тот, чей chat id в `TELEGRAM_CHAT_ID`) отправляет другу ссылку на бота.
- Друг пишет боту. Бот отвечает, что запрос у владельца, а владельцу приходит
  «👤 … хочет пользоваться ботом. Пустить?» с кнопками «✅ Пустить» и «🚫 Нет».
- Пущенный человек получает своё меню: свои направления, поезда и уведомления
  («ИМЯ СРОЧНО …»). Чужие настройки никто не видит.
- В меню владельца есть «👥 Друзья»: кто пользуется ботом, кто просится, ссылка на бота,
  кнопка «Убрать». Убранный человек может написать снова, тогда придёт новый запрос.
- Тем, кому отказали, бот больше не отвечает (в «👥 Друзья» можно «Всё-таки пустить»).
  В группах бот не работает.
- Доступ хранится в `data/access.json`, настройки друзей в `data/users/<chat id>/`.

## Работа на своём сервере (ответы сразу)

На сервере с Ubuntu выполни:

```
git clone <адрес репозитория> /opt/avia-bot && sudo bash /opt/avia-bot/install.sh
```

Скрипт спросит три токена, создаст службу `avia-bot` и запустит её. После этого
расписание в `.github/workflows/check.yml` нужно выключить, чтобы бот не работал
в двух местах сразу.

- Логи: `journalctl -u avia-bot -f`
- Обновить код: `cd /opt/avia-bot && git pull && systemctl restart avia-bot`
